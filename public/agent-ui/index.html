how it works

Small on the desktop, strict under the hood.

Hermes platform adapters connect an external surface to the gateway, then let Hermes route the message to the agent. agent-UI follows that shape for macOS instead of adding a parallel tool system or hidden runtime.

agent-UI does
  • Registers the local_desktop platform plugin with Hermes.
  • Sends prompts and lightweight desktop context to the gateway.
  • Surfaces setup values through Hermes-owned provider/model configuration.
  • Shows output, follow-up, cancel, voice, reconnect, and active-run state.
agent-UI does not
  • Bundle or fork the Hermes runtime.
  • Store provider credentials or model secrets.
  • Own transcript, memory, or conversation history.
  • Copy tools or agent behavior into the user's Hermes tree.
